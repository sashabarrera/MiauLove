# Examen de Certificación - MiauLove

## Descripción
Este proyecto es una aplicación web sobre gatitos realizada para la evaluación del módulo. La interfaz incluye un menú lateral con accesos directos, un encabezado con buscador, un título principal, botones para filtrar categorías y tarjetas con imágenes que permiten interactuar marcando "Me gusta".

## Estructura de archivos
- index.html (Estructura de la aplicación)
- README.md (Descripción e instrucciones)
- .gitignore (Archivos ignorados del sistema)
- static/css/style.css (Estilos y diseño de la página)
- static/js/script.js (Lógica e interacciones de la página)
- static/images/ (Recursos gráficos e imágenes)

## Instrucciones para abrir y probar la aplicación
1. Descargar y descomprimir la carpeta del examen.
2. Abrir la carpeta y hacer doble clic en el archivo `index.html` para ejecutarlo en el navegador.
3. Hacer clic en los botones de categorías (Gatitos, Juveniles, Adultos) para comprobar el cambio de color al seleccionar.
4. Presionar el botón con el corazón en cualquiera de las tarjetas para verificar que el contador de me gusta aumente.
5. Hacer clic en el botón de Cerrar Sesión en la barra lateral para ver la alerta de confirmación.
